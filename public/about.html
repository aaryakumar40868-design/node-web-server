02 — ABOUT THE PROJECT

Small server.
Clear journey.

This project shows what happens between typing a URL and seeing a page. Express matches the route, then Node.js sends the right HTML file back to your browser.

01
THE VISITOR

Browser makes a request

A visit to /about arrives as an HTTP GET request.

⌕
02
THE SERVER

Express finds the route

The matching handler picks the page using its path.

{ }
03
THE RESPONSE

HTML goes back to the browser

res.sendFile() delivers the page; Express serves the shared stylesheet.

↗

THE ROUTE MAP

Every path has a purpose.

METHODPATHWHAT HAPPENS
GET/Serves the home page
GET/aboutServes the about page
GET/contactServes the contact form
POST/contactValidates form, then redirects
ANY* (fallback)Returns the custom 404 page
i

A note about the form: it checks each field on the server and redirects with a success or error status. This demo doesn’t save or email submitted messages.
